# Maker Thursday

Maker Thursday is a **weekly, community-driven gathering** at TinkerSpace where makers come together to share ideas, build projects, and learn from each other.

This repository documents Maker Thursday sessions and serves as a public archive of activities, discussions, and community contributions.

---

## 📘 What This Repository Contains

- Weekly **Maker Thursday journal entries**
- Session summaries, project notes, and highlights
- A record of community and host contributions

---

## ✍️ Contributing

Each Maker Thursday session is documented by its host(s).

- Hosts create a journal entry for their session
- Contributions are made via GitHub pull requests
- Multiple authors are supported for co-hosted sessions

See **`How to Contribute`** for detailed guidelines.
